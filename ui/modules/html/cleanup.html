Disk & System Cleanup

Free up disk space and flush temporary caches using core system APIs.

Empty Recycle Bin

Calls SHEmptyRecycleBinA API to instantly clear all deleted files without confirmation prompts or progress UI.

Clear Temp Files & Caches

Recursively deletes files from User Temp, Windows\Temp, Prefetch, and SoftwareDistribution\Download.

SSD TRIM (C:\)

Runs defrag C: /L /O to execute a manual TRIM command, telling the SSD controller to wipe deleted blocks immediately for peak write speeds.

HDD Defragment (C:\)

Runs standard defragmentation (defrag C: /O) to consolidate file fragments on mechanical hard drives. Do not run on SSDs.

Network & TCP/IP Reset

Flush DNS cache and rebuild the Winsock catalog to fix connection issues.

Flush DNS Cache

Runs ipconfig /flushdns to clear local DNS resolver cache. Fixes issues where domains point to old or incorrect IPs.

Reset Winsock Catalog

Runs netsh winsock reset to restore TCP/IP stack to clean state. Requires system restart to take effect.

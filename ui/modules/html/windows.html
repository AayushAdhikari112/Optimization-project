Input Optimization

Optimize mouse/keyboard latency and disable intrusive accessibility shortcuts that trigger during gaming.

Disable Mouse Acceleration

Turns off Windows "Enhance Pointer Precision" via SPI_SETMOUSE. Ensures 1:1 raw input and consistent muscle memory for FPS games.

Disable Sticky Keys

Turns off Sticky Keys via SPI_SETSTICKYKEYS API. Prevents the game-minimizing prompt when pressing SHIFT 5 times quickly.

Disable Filter Keys

Turns off Filter Keys via SPI_SETFILTERKEYS API. Prevents ignored keystrokes if you hold a key down for too long (e.g. running in games).

Windows Debloat & Privacy

Disable built-in Windows telemetry, ads, and unnecessary data collection.

Disable Windows Telemetry

Sets AllowTelemetry = 0 to stop Windows from sending background diagnostic data to Microsoft.

Disable Cortana & Search Web Results

Disables Cortana and prevents the Start Menu from searching Bing (reducing web lag when searching local files).

Disable Lock Screen Ads

Disables Windows Spotlight and "Fun facts, tips, tricks" ads on the Windows lock screen.

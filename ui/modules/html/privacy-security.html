Telemetry & Privacy

Stop unnecessary background data collection to save resources and protect privacy.

Data Collection 🟠 ADVANCED
Connected User Experiences and Telemetry
StatusRunning (Full Data)
Background ImpactHigh CPU / Disk I/O
Recommendation
DISABLE
Why? The Windows Telemetry service (DiagTrack) constantly runs in the background, collecting usage data, keystrokes, and system metrics to send to Microsoft. This consumes CPU cycles and disk bandwidth unnecessarily. Disabling it improves privacy and system responsiveness.
Tracking 🟡 MODERATE
Activity History & Timeline
StatusEnabled
Cloud SyncActive
Recommendation
DISABLE
Why? Windows tracks the apps you use, files you open, and websites you browse to create an "Activity History." If cloud sync is on, this data is uploaded. Disabling it stops local caching and network uploads, freeing up small amounts of resources.
Sensors 🟡 MODERATE
Location Tracking Service
StatusEnabled
Device TypeDesktop PC
Recommendation
DISABLE FOR DESKTOPS
Why? The Windows Location Service runs in the background to provide location data to apps like Weather or Maps. On a stationary Desktop PC, this is largely unnecessary. Disabling it stops the background polling. (Note: Keep enabled on laptops if you use Find My Device).

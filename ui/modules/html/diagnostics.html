System Health & Diagnostics

Check hardware health status, SMART data, and run integrity scans.

Check Storage Health (SMART)

Runs wmic diskdrive get status to check hardware-reported SMART status of all connected drives.

System File Checker (SFC)

Runs sfc /scannow to verify and repair corrupted Windows system files. ⚠ Can take 10-20 minutes.

DISM Component Repair

Runs DISM /Online /Cleanup-Image /RestoreHealth to repair the Windows component store. ⚠ Requires internet.

Schedule Check Disk (CHKDSK)

Runs chkdsk C: /f /x to schedule a disk error scan and repair on the next system reboot.

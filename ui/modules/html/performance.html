Power State 🟡 MODERATE
Windows Hibernation (hiberfil.sys)
StatusEnabled
Disk Space Used6.4 GB
Recommendation
DISABLE FOR DESKTOPS
Why? Hibernation saves your RAM to the hard drive (hiberfil.sys) before powering off. On modern SSDs, booting from scratch is incredibly fast, rendering Hibernation mostly obsolete for desktops. Disabling it instantly frees up gigabytes of SSD space and reduces SSD wear and tear. (Keep enabled on laptops if you want to save battery when the lid is closed for days).
Hardware Sleep State 🟠 ADVANCED
S3 Legacy Sleep State
StatusS0 Modern Standby Active
Hardware SupportS3 Supported
Recommendation
FORCE S3 SLEEP
Why? Modern Windows devices use "S0 Modern Standby," which functions like a smartphone (always connected, always draining battery). "S3 Sleep" is the legacy sleep mode that completely powers down most hardware, drastically extending battery life while asleep. Forcing this requires a registry change and a reboot.

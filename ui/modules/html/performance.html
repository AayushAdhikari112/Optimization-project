CPU Optimization

Tune processor throttling, gaming profiles and scheduling via powercfg.

Apply Gaming Profile

Sets CPU Min/Max throttle (5%–100%) via powercfg PROCTHROTTLEMIN/MAX. Prevents aggressive clock-speed drops during gaming sessions.

Restore Default CPU Profile

Resets CPU performance state back to Windows safe defaults (5%–100% throttle range). Run after gaming to reduce heat.

MMCSS Gaming Priority

Sets Multimedia Class Scheduler Service (MMCSS) CPU priority for Games class — reduces micro-stutter in competitive titles.

Disable Power Throttling

Disables Windows Power Throttling which intentionally slows background processes. Improves CPU responsiveness for foreground apps and games.

Set Interrupt Priority (MSI Util)

Opens MSI Util v3 to enable Message Signaled Interrupts and set device interrupt priority — reduces DPC latency for GPU and NIC.

GPU Optimization

Power profiles and hardware scheduling — from gpu_optimizer.c via powercfg and registry.

High Performance GPU Profile

Activates High Performance power plan GUID 8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c — tells Windows to push maximum GPU clocks.

Balanced GPU Profile

Reverts to Balanced power plan 381b4222-f694-41f0-9685-ff5bb260df2e — quieter fans and lower heat for everyday use.

Enable Hardware-Accelerated GPU Scheduling (HAGS)

Sets HwSchMode = 2 in HKLM\SYSTEM\...\GraphicsDrivers. Moves GPU memory management to the GPU, reducing CPU overhead and latency.

Disable Hardware-Accelerated GPU Scheduling

Sets HwSchMode = 1 — reverts HAGS to classic CPU-controlled GPU scheduling. Recommended for older drivers or DX11 games with stutters.

Disable Fullscreen Optimizations

Sets DisabledMaximizedWindowedMode globally — forces games into exclusive fullscreen, reducing compositor overhead and input lag.

Power & Display (Extra)

Power plans via power_optimizer.c and refresh rate via screen_optimizer.c.

High Performance Power Plan

Activates GUID 8c5e7fda… — disables all CPU/GPU sleep states for maximum sustained performance.

Balanced Power Plan

Reverts to Windows Balanced plan 381b4222… — good for battery life and daily workloads.

Power Saver Plan

Activates Power Saver GUID a1841308… — aggressively throttles CPU/GPU for extended battery life on laptops.

Disable USB Selective Suspend

Prevents Windows from powering down idle USB ports (powercfg AC+DC index 0). Eliminates controller/headset disconnect issues during gaming.

Maximize Refresh Rate

Uses screen_optimizer.c → set_display_refresh_rate() to set display to highest supported Hz via ChangeDisplaySettings API.

Disable Network Throttling

Sets NetworkThrottlingIndex = 0xffffffff and SystemResponsiveness = 0 — removes Windows MMCSS network bandwidth cap for gaming.

Gaming Mode

One-click bundle of every real gaming optimization from the C backend.

One-Click Gaming Bundle

Runs: CPU Gaming Profile + High Perf GPU + HAGS ON + Disable Power Throttling + MMCSS Priority + Disable USB Suspend + Disable Network Throttling.

Enable Windows Game Mode

Enables Windows built-in Game Mode which prioritises CPU/GPU resources to the active game process and limits background updates.

Disable Xbox Game Bar

Disables Game Bar and DVR (GameDVR_Enabled = 0) — removes overlay, stops background recording and reduces CPU/disk usage in game.

Create Restore Point First

Uses safety_engine.c → create_restore_point() — creates a Windows system restore point named "Pre-Gaming-Tweaks" before applying changes.

Weak PC / Startup Manager

Low-resource optimizations + startup app control via startup_manager.c registry enumeration.

Scan Startup Apps

Reads HKCU\...\Run and HKLM\...\Run registry keys — lists every program that launches at Windows startup and may slow boot.

Free Up RAM (Empty Working Sets)

Calls EmptyWorkingSet() on every running process via EnumProcesses — flushes RAM pages back to disk, reclaiming physical memory immediately.

Disable Visual Effects (Best Performance)

Sets VisualFXSetting = 2 — disables animations, shadows, transparency and Aero effects. Best for low-end PCs under 4GB RAM.

Optimize Paging File

Sets LargeSystemCache = 0 and DisablePagingExecutive = 1 — keeps kernel in RAM instead of paging to disk, boosting low-RAM system responsiveness.

Disable SysMain (Superfetch)

Stops and disables SysMain service — on low-RAM systems (<8GB) Superfetch causes constant HDD thrashing. Free up disk I/O immediately.

Services Optimizer

Manage Windows background services for performance gains.

SysMain (Superfetch)

Preloads frequently used apps into RAM. Disable if on SSD with <8GB RAM.

Windows Search (WSearch)

Stops file indexing service. Reduces disk I/O if you rarely use Windows search.

Windows Update (Disable Bandwidth Drain)

Pauses automatic Windows Update delivery to free up CPU and network during gaming sessions.

Connected Devices Platform (CDPSvc)

Disables timeline sync and cross-device clipboard. Reduces background CPU wakeups.
